# Источник данных

Оригинальные файлы `gt_2011.csv` — `gt_2015.csv` загружены из [Gas Turbine CO and NOx Emission Data Set](https://archive.ics.uci.edu/dataset/551/gas%2Bturbine%2Bco%2Band%2Bnox%2Bemission%2Bdata%2Bset), UCI Machine Learning Repository, DOI [10.24432/C5WC95](https://doi.org/10.24432/C5WC95). Лицензия источника — [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Файлы не изменены. Происхождение года определяется именем файла в `analysis.py`.
